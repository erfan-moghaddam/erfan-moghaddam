## About Me

I am an Android developer focused on turning product requirements and UI designs into reliable, production-ready mobile applications.

I primarily work with **Kotlin** and **Jetpack Compose**, using maintainable architectural approaches such as **MVVM** and **Clean Architecture**.

My work covers more than building application screens. I focus on engineering areas that directly affect application reliability and maintainability:

- REST API integration
- Authentication and session management
- Access-token and refresh-token workflows
- Structured error handling
- Predictable application state
- Reusable Compose components
- Multilingual and localized interfaces
- Maintainable project architecture
- Debugging and refactoring existing codebases

I also use **Python** to develop supporting APIs, automation tools and data-processing components.
